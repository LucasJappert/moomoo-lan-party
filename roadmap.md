# 🗺️ MooRaiders Roadmap - Versión Jugable en 2 Meses

Este documento contiene el plan detallado para completar una versión jugable y disfrutable de MooRaiders. El enfoque está en implementar las mecánicas principales, los sistemas de juego base, y preparar el terreno para la iteración futura y monetización.

---

## ✅ Prioridades Generales

- Crear una experiencia base divertida y funcional.
- Incluir al menos 3 héroes únicos con habilidades.
- Sistema de oleadas con enemigos que atacan la estatua central.
- Progreso, oro, niveles y mejoras básicas.
- Interfaz clara y con buen feedback visual/sonoro.

---

## 📅 Plan por Fechas

### 📅 30/06/2025 - Semana 1-2: Pulido base y núcleo del juego

- [x] 3 héroes jugables con al menos 2 habilidades
- [ ] Pantalla de inicio y selector de héroes
- [ ] Gameplay central sólido (moverse, atacar, oleadas, defensa)
- [ ] Agregar efectos de sonido y visuales
- [ ] IA enemiga básica con mínima diversidad
- [ ] Sistema de oleadas desde esquinas del mapa
- [ ] Estatua central funcional (vida, daño, derrota)
- [ ] IA mejorada para priorizar jugador o estatua

### 📅 14/07/2025 - Semana 3-4: Menús y presentación

- [ ] Balance básico de dificultad y progresión
- [ ] Identidad visual consistente y música de fondo
- [ ] Panel de habilidades, mejoras y retroalimentación visual
- [ ] Indicadores de progreso (oleadas, oro, EXP)
- [ ] Efectos visuales básicos (explosiones, stun, partículas)
- [ ] Sonidos al golpear, matar, recibir oro/exp.
- [ ] Animaciones de muerte y habilidades

### 📅 28/07/2025 - Semana 5-6: Primer testeo abierto

- [ ] Corregir bugs y hacer playtesting interno
- [ ] Crear versión exportable (Linux/Windows/Web)
- [ ] Recibir feedback real de amigos/jugadores
- [ ] Interfaz completa con HUD, vida, habilidades y oro
- [ ] Transiciones de pantalla, inicio y derrota
- [ ] Ajustes de balance (dificultad progresiva)

### 📅 14/08/2025 - Post-demo: Difusión y primeros pasos de escalamiento

- [ ] Iterar el gameplay en base al feedback
- [ ] Crear video trailer y capturas
- [ ] Subir a itch.io o página propia
- [ ] Compartir en comunidades (Reddit, Discord, etc.)
