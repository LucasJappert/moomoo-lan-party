# 🗺️ MooRaiders Roadmap – Playable Build in 2 Months

This document outlines the plan to deliver a fun, playable version of MooRaiders. The focus is on core mechanics, foundational systems, and setting up for future iteration and monetization.

---

## ✅ General Priorities

- Build a fun, functional core experience.
- Include at least 3 unique heroes with abilities.
- Wave system with enemies attacking the central statue.
- Progression, gold, levels, and basic upgrades.
- Clear UI with strong visual/audio feedback.

---

## 📅 Date-based Plan

### 📅 June 30, 2025 — Weeks 1–2: Core polish & game loop

- [x] 4 playable heroes with 4 abilities each
- [x] Start screen and hero selection
- [x] Screen transitions, start, and defeat screens
- [x] Solid core gameplay loop (movement, attacks, waves, defense)
- [x] Add SFX and VFX
- [x] Basic enemy AI with minimal variety
- [x] Functional central statue (HP, damage, defeat)
- [x] Improved AI to prioritize player or statue

### 📅 July 14, 2025 — Weeks 3–4: Menus & presentation

- [x] Wave system spawning from map corners
- [x] Basic balance for difficulty and progression
- [x] Consistent visual identity and background music
- [x] Ability panel, upgrades, and visual feedback
- [x] Progress indicators (waves, gold, EXP)
- [x] Basic VFX (explosions, stun, particles)
- [x] Sounds for hits, kills, gold/exp rewards
- [x] Death and ability animations

### 📅 July 28, 2025 — Weeks 5–6: First open testing

- [ ] Fix bugs and run internal playtests
- [ ] Create exportable builds (Linux/Windows/Web)
- [ ] Gather real feedback from friends/players
- [x] Complete HUD: health, abilities, gold
- [x] Balance tweaks (progressive difficulty)

### 📅 August 14, 2025 — Post-demo: Outreach & early scaling

- [ ] Iterate gameplay based on feedback
- [ ] Create a trailer and screenshots
- [ ] Publish on itch.io or a dedicated site
- [ ] Share in communities (Reddit, Discord, etc.)

---

## 🧪 Nice-to-haves (time permitting)

- [ ] Achievement or challenge system
- [ ] Local save system
- [ ] Basic graphics options for performance

---

## 🎯 Final Goal

Ship a playable, polished, and presentable version of MooRaiders that serves as a strong foundation to grow, inspire others, and eventually monetize. 🚀
